# Hiro-AI

Hiro is a networked AI secretary where each person has their own assistant, and those assistants communicate with each other to coordinate tasks, schedules, updates, and responsibilities automatically.

## Snake demo

This repo includes a playable Snake game (desktop + mobile web).

### Play it yourself

| Platform | How |
|----------|-----|
| **Phone / mobile web** | Open [docs/index.html](./docs/index.html) via [GitHub Pages preview](https://htmlpreview.github.io/?https://github.com/ichigokekiii/Hiro-AI/blob/cursor/snake-desktop-app-bc68/docs/index.html) |
| **Desktop (Python)** | `pip install -r requirements.txt && python3 snake.py` |
| **Web (local)** | `./scripts/serve-web-snake.sh` then open http://127.0.0.1:8080/ |
